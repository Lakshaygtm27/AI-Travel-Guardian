# Backup demo runbook

Record the following screens in OBS Studio or Loom while local services are running:

1. Open the Command Center and create Delhi -> Jaipur, 3 days, INR 10,000 in Planner.
2. Generate the Ollama itinerary and show morning, afternoon, and evening entries.
3. Show the Command Center risk score, weather, budget burn rate, radar, and map.
4. Open Budget and show the donut, pie, and area burn-rate charts.
5. Open Emergency, allow browser location, press SOS, and open the generated route.
6. Open Weather and show temperature, rain, wind, and the recommendation state.
7. Press Replan trip after setting rain above 50% and show Amber Fort -> Albert Hall Museum.
8. Import the n8n trip-created workflow and show the PDF -> email nodes.

Before recording, start the backend on port 8001, the frontend on port 5173, Docker PostgreSQL, Docker Ollama, and n8n on port 5678. Keep this recording available offline for judging.
